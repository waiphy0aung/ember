# Ember

A personal Android todo app where every task is a flame. Flames burn out if you don't act on them; finished ones become stars in your sky.

- **Specification:** the "Ember — Requirements" doc (requirements, data model, flows, architecture, coding standards, operations, build plan).
- **Install:** stable builds are published as GitHub Releases (`v0.<milestone>.<n>`); pull requests publish "Ember Preview" pre-releases. Obtainium on the phone installs and updates both.
- **Build:** Kotlin, Jetpack Compose, Room. JDK 21, then `./gradlew :app:assemblePreview`.
